Repositório desenvolvido como **projeto de estudos do curso da DIO.me**, dedicado à organização de conhecimentos, anotações e materiais sobre a **Lei Geral de Proteção de Dados Pessoais (LGPD)**, com apoio da ferramenta **NotebookLM** para pesquisa, síntese e aprendizagem estruturada.

---

## 🎯 Sobre o Projeto

Este repositório reúne uma compilação organizada de materiais educacionais sobre proteção de dados pessoais, privacidade digital e conformidade com a legislação brasileira de proteção de dados. O objetivo é transformar fontes extensas em anotações práticas, resumos concisos e conceitos aplicáveis.

Além disso, o projeto demonstra como ferramentas modernas de inteligência artificial — como o **NotebookLM** — podem otimizar a organização, síntese e compreensão de conteúdos durante o processo de aprendizagem contínua.

---

## 🎓 Objetivos de Aprendizagem

- ✅ Dominar os conceitos fundamentais e princípios da LGPD;
- ✅ Compreender os direitos dos titulares de dados pessoais;
- ✅ Identificar as obrigações e responsabilidades de organizações que tratam dados;
- ✅ Aplicar boas práticas de conformidade e segurança da informação;
- ✅ Documentar e organizar o conhecimento adquirido de forma clara e acessível;
- ✅ Demonstrar a aplicação de ferramentas de IA para otimizar estudos;
- ✅ Criar um material de referência para consulta futura.

---

## 📖 Temas Principais Abordados

| Tema | Descrição |
|------|-----------|
| **Fundamentos da LGPD** | Conceitos essenciais, histórico e aplicabilidade da lei |
| **Dados Pessoais** | Classificação, tipos e sensibilidade de dados |
| **Direitos do Titular** | Direito de acesso, retificação, exclusão e portabilidade |
| **Princípios** | Transparência, finalidade, necessidade, segurança e outros |
| **Bases Legais** | Fundamentos para o tratamento de dados pessoais |
| **Agentes** | Papéis de controlador, operador e encarregado |
| **Segurança** | Medidas de proteção, criptografia e prevenção de incidentes |
| **Conformidade** | Implementação de políticas e processos de compliance |

## 🚀 Como Utilizar Este Repositório

### Para Iniciantes em LGPD:
1. Comece pelo arquivo `anotacoes/conceitos-chave.md` para uma visão geral;
2. Consulte o `anotacoes/glossario-lgpd.md` para esclarecimentos de termos;
3. Explore os notebooks para aprofundamento em tópicos específicos;
4. Verifique as referências oficiais em `recursos/`.

### Para Profissionais:
1. Acesse `notebooks/` para análises estruturadas;
2. Consulte `anotacoes/casos-de-uso.md` para aplicações práticas;
3. Use `recursos/documentos-anpd.md` para orientações normativas.

## 🤖 O Papel do NotebookLM

O **NotebookLM** é utilizado neste projeto como ferramenta de apoio para:

- 🔍 **Sintetizar** conteúdos de fontes oficiais e acadêmicas;
- 📊 **Organizar** conceitos em estruturas lógicas e acessíveis;
- ❓ **Gerar** perguntas e respostas sobre os materiais estudados;
- 🔗 **Conectar** diferentes tópicos e fundamentos;
- 📌 **Destacar** pontos críticos e aplicáveis.

> **⚠️ Importante:** As informações geradas são sempre conferidas nas fontes originais. O NotebookLM é um recurso de apoio à aprendizagem, não substitui legislação oficial, fontes autoridades ou consultoria especializada.
