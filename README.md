# miniguia-estudos-notebooklm

Repositório de estudos sobre tema de interesse pela LGPD

## 📋 Objetivo

Este repositório serve como um **mini guia de estudos** focado em questões relacionadas à **Lei Geral de Proteção de Dados (LGPD)** e tópicos afins. O material é organizado em formato de notebooks e anotações de estudo para facilitar o aprendizado progressivo.

## 🎯 Finalidade

- Consolidar conhecimento sobre LGPD e conformidade de dados
- Servir como referência rápida e estruturada
- Organizar estudos temáticos de interesse particular
- Documentar achados e insights sobre proteção de dados

## 📚 Estrutura

```
miniguia-estudos-notebooklm/
├── README.md (este arquivo)
├── notebooks/ (estudos detalhados)
├── anotacoes/ (resumos e insights)
└── recursos/ (links e referências)
```

## 🔍 Tópicos Abordados

- Princípios da LGPD
- Direitos do titular de dados
- Obrigações das organizações
- Conformidade e compliance
- Tratamento de dados pessoais
- Segurança da informação

## 🚀 Como Usar

1. Navegue pelos diretórios para encontrar o tema de interesse
2. Abra os notebooks no formato que preferir
3. Consulte as anotações para resumos rápidos
4. Verifique os recursos para materiais complementares

## 📝 Notas

Este é um projeto pessoal de estudos em andamento. Sugestões e contribuições são bem-vindas!
