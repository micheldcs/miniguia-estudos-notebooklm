# Mini Guia de Estudos sobre a LGPD com NotebookLM

Repositório desenvolvido como projeto de estudos do curso da **DIO.me**, com o objetivo de organizar conhecimentos, referências e aprendizados sobre a **Lei Geral de Proteção de Dados Pessoais (LGPD)** utilizando o **NotebookLM** como apoio à pesquisa e à aprendizagem.

## 📌 Sobre o projeto

Este projeto reúne materiais de estudo sobre proteção de dados pessoais, privacidade e conformidade com a LGPD. A proposta é transformar conteúdos extensos em anotações, resumos e entendimentos práticos que facilitem a revisão e o compartilhamento do conhecimento.

O repositório também demonstra como ferramentas de inteligência artificial, como o NotebookLM, podem apoiar a organização e a compreensão de fontes confiáveis durante um processo de aprendizagem.

## 🎯 Objetivos

- Estudar os principais conceitos e fundamentos da LGPD;
- Organizar fontes, anotações e resumos em um único local;
- Desenvolver uma visão introdutória sobre privacidade e proteção de dados;
- Utilizar o NotebookLM como ferramenta de apoio à pesquisa e à revisão;
- Documentar a evolução do aprendizado ao longo do projeto da DIO.me;
- Compartilhar um material simples e acessível para consulta.

## 📚 Conteúdos abordados

- Conceitos fundamentais da LGPD;
- Dados pessoais e dados pessoais sensíveis;
- Titular dos dados e seus direitos;
- Princípios da proteção de dados;
- Bases legais para o tratamento de dados;
- Agentes de tratamento: controlador e operador;
- Encarregado pelo tratamento de dados pessoais;
- Segurança da informação e prevenção de incidentes;
- Privacidade e responsabilidade no uso de dados;
- Boas práticas de conformidade.

## 🗂️ Estrutura sugerida

```text
miniguia-estudos-notebooklm/
├── README.md
├── notebooks/      # Materiais e registros produzidos no NotebookLM
├── anotacoes/      # Resumos, conceitos e aprendizados
└── recursos/       # Links, fontes e referências complementares
```

## 🚀 Como utilizar este repositório

1. Comece pela leitura deste README;
2. Consulte a pasta `anotacoes` para obter uma visão resumida dos temas;
3. Acesse a pasta `notebooks` para acompanhar os estudos realizados com o NotebookLM;
4. Consulte a pasta `recursos` para conhecer as fontes utilizadas;
5. Use o conteúdo como apoio para revisão e aprofundamento.

## 🤖 Papel do NotebookLM

O NotebookLM é utilizado neste projeto como ferramenta de apoio para:

- resumir conteúdos fornecidos como fonte;
- facilitar a identificação de conceitos importantes;
- organizar perguntas e respostas sobre os materiais;
- apoiar a comparação entre diferentes referências;
- auxiliar na revisão dos estudos.

As informações geradas pela ferramenta devem ser conferidas nas fontes originais. O NotebookLM é um recurso de apoio e não substitui a leitura da legislação, de fontes oficiais ou a orientação de profissionais especializados.
